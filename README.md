# Staročeská Chalupa – publikovaný web

Tento veřejný repozitář obsahuje vygenerovaný statický web.

Zdrojové šablony, SASS, JavaScript a překladová paměť se udržují v odděleném
zdrojovém repozitáři. Obsah tohoto repozitáře aktualizuje automaticky GitHub
Actions po pushi do zdrojové větve `main`.

Vygenerované soubory neupravuj ručně.
